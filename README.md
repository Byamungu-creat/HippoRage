🦛 **RAGEHIPPO** is a powerful and stylized meme coin designed for community-driven fun and value creation.

- **Token Name**: RAGEHIPPO  
- **Symbol**: RAGE  
- **Total Supply**: 690,000,000,000 RAGE  
- **Decimals**: 18  
- **Blockchain**: Binance Smart Chain (BEP-20)  
- **Contract Address**: 0xF509F37d52D7eb451bb677B1254781d74FB109Fc

## ⚙️ Features

- **Automated Vault System**  
- **Burn and Mint Mechanisms**  
- **Blacklist & Fee Exemptions**  
- **Airdrop Functions**  
- **Max Supply & Transaction Limits**
